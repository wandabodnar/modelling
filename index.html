Statistical modelling for ecological survey data

Author

Wanda Bodnar

Purpose

This tutorial starts with raw, long-format fish-survey data allowing to practise the full workflow:

raw data → data checks → exploratory analysis → derive response variables → choose a model → fit candidate models → diagnostics → interpretation → estimated marginal means

Please note that the example data are entirely synthetic.

Data wrangling

Create total abundance per survey

The response total fish abundance is derived by summing all fish counts within each survey.

abundance_observed <- fish_raw %>%
  group_by(SURVEY_ID) %>%
  summarise(
    Abundance = sum(FISH_COUNT, na.rm = TRUE),
    .groups = "drop")

Join abundance to the complete survey universe creating a survey abundance dataset:

survey_abundance <- survey_universe %>%
  left_join(
    abundance_observed,
    by = "SURVEY_ID") %>%
  mutate(
    Abundance = replace_na(Abundance, 0))

This is where the raw species-level table is converted into one abundance value per survey. This ensures that the final abundance dataset contains one row for every survey, including genuine zero-catch surveys.

Preparing the model

Centre year

This is to make the model easier to interpret and sometimes easier to fit numerically.

year_centre <- mean(survey_abundance$YEAR)

Variables

Abundance:

survey_abundance <- survey_abundance %>%

    YEAR_CENTERED = YEAR - year_centre, # helps estimate a continuous temporal trend with a meaningful zero

Residuals (observed - model predicated values) represent the variation in abundance that remains after the model has accounted for year and sampling month.

\[ \text{Residual} = \text{Observed} - \text{Predicted} \]

    survey_abundance$SITE,

abline(h = 0, lty = 2)

By plotting these residuals separately for each monitoring site, we can ask whether the simple LM systematically overpredicts or underpredicts abundance at particular sites.

If residuals are consistently positive or negative at some sites, then site identity explains additional structure that is not captured by year and month alone. This provides evidence that observations are grouped by site and motivates the inclusion of a site-level random intercept in a linear mixed-effects model.

Generalized linear mixed model (GLMM)

A generalized linear mixed model is used when:

  • the response variable is not well suited to a normal/Gaussian model;
  • observations are grouped or repeated;
  • both fixed and random effects are needed.

A GLMM combines a GLM with random effects and can be fitted using the glmmTMB() function. Many of the same family choices apply, including Gaussian, binomial, Poisson, negative binomial, COM-Poisson, generalized Poisson, Gamma, Beta and Tweedie. However, quasi-families such as quasipoisson() and quasibinomial() are not supported by glmmTMB().

Modelling summary

Estimated marginal means (EMMs)

Estimated marginal means are model-adjusted expected values. They are useful when a fitted model contains other predictors that also influence the response.

For example, if abundance or richness varies among sampling months, the raw annual mean may partly reflect which months happened to be sampled in that year.

An EMM asks:

What does the fitted model estimate for a particular year after accounting for the other terms in the model?

This is different from a raw arithmetic mean.

Raw mean versus EMM

Quantity Question
Raw mean What was the arithmetic mean of the surveys actually conducted that year?
EMM What is the model-adjusted expected value for that year after accounting for the other model terms?

For example, if one year was sampled mostly in months with naturally high fish abundance, its raw annual mean may be relatively high. The EMM adjusts for this imbalance using the fitted model.

Why use Year as a factor?

The continuous-year model: Response ~ YEAR_CENTERED + … answers:

What is the overall long-term rate of change?

The factor-year model: Response ~ YEAR_FACTOR + … answers:

What is the adjusted expected richness in each sampled year?

## Residuals

Residuals (observed - model predicated values) represent the variation in abundance that remains after the model has accounted for year and sampling month.

$$
\text{Residual} = \text{Observed} - \text{Predicted}
$$

Inspect residuals among sites:

```{r}
boxplot(
  residuals(m_abundance_lm) ~
    survey_abundance$SITE,
  xlab = "Monitoring site",
  ylab = "LM residuals",

abline(h = 0, lty = 2)
```

By plotting these residuals separately for each monitoring site, we can ask whether the simple LM systematically overpredicts or underpredicts abundance at particular sites.

If residuals are consistently positive or negative at some sites, then site identity explains additional structure that is not captured by year and month alone. This provides evidence that observations are grouped by site and motivates the inclusion of a site-level random intercept in a linear mixed-effects model.

```{r}
  Log_Abundance ~
    YEAR_CENTERED +              # long-term temporal trend
    MONTH_FACTOR +               # adjust for seasonal sampling
    (1 | SITE) +                 # persistent baseline differences among sites
    (1 | SITE_YEAR),             # clustering of repeated surveys within site-years
  data = survey_abundance,
  REML = TRUE)                   # restricted maximum likelihood, estimate final Gaussian mixed model using REML

summary(m_abundance_lmm)
```

Interpretation:

- `YEAR_CENTERED`: overall temporal trend;
- `MONTH_FACTOR`: seasonal adjustment;
- `(1 | SITE)`: persistent differences among sites;
- `(1 | SITE_YEAR)`: repeated surveys within site-years.

# Generalized Linear Model (GLM)

A generalized linear model extends a standard linear model so that the response variable does not have to be normally distributed. `glm()` function is used.

A GLM is useful when the response has a different form, for example:

- binary data;
- count data;
- proportions;
- positive skewed continuous data.

```{r}
m_richness_glm <- glm(
  Richness ~ YEAR_CENTERED + MONTH_FACTOR,
  data = survey_richness,
  family = poisson(link = "log")) #  ensures that predicted richness remains positive.

summary(m_richness_glm)
```

## Common model families

For `glm()`, the family tells R what kind of response distribution to expect. The link tells R how the expected response is connected to the linear predictor.

| Family | Typical response | Dispersion handled | Common link | Example / when useful |
|---|---|---|---|---|
| **Gaussian** | Continuous, approximately normal | — | `identity` | Length, temperature |
| **Binomial** | Binary / success-failure / proportions from counts | Standard binomial variance | `logit` | Present / absent |
| **Poisson** | Counts | Assumes variance approximately equals mean | `log` | Species richness, count data |
| **Negative binomial** | Counts | Overdispersion | `log` | Counts with variance greater than the mean |
| **COM-Poisson** | Counts | Underdispersion or overdispersion | usually `log` | Flexible count model when Poisson dispersion is violated |
| **Generalized Poisson** | Counts | Underdispersion or overdispersion | usually `log` | Flexible alternative to standard Poisson |
| **quasipoisson** | Counts | Overdispersion | `log` | Overdispersed counts; no likelihood/AIC |
| **Gamma** | Positive continuous, right-skewed | — | often `log` | Biomass, duration, concentration |
| **Inverse Gaussian** | Positive continuous, strongly right-skewed | — | often `1/mu^2` or `log` | Strongly skewed positive measurements |
| **quasibinomial** | Binary / proportion data | Extra dispersion | `logit` | Overdispersed proportion data |
| **Beta** | Continuous proportions between 0 and 1 | Flexible | usually `logit` | Habitat cover proportion |
| **Tweedie** | Non-negative continuous data, often with zeros | Flexible | often `log` | Biomass or other zero-plus-positive continuous data |

# Generalized linear mixed model (GLMM)

A generalized linear mixed model is used when:

- the response variable is not well suited to a normal/Gaussian model;
- observations are grouped or repeated;
- both fixed and random effects are needed.

A GLMM combines a GLM with random effects and can be fitted using the `glmmTMB()` function. Many of the same family choices apply, including Gaussian, binomial, Poisson, negative binomial, COM-Poisson, generalized Poisson, Gamma, Beta and Tweedie. However, quasi-families such as `quasipoisson()` and `quasibinomial()` are not supported by `glmmTMB()`.

## Interpreting the abundance LMM

The main outputs of interest are:

| Output | What it tells us | Where it comes from |
|---|---|---|
| **Intercept** | Expected `Log_Abundance` at `YEAR_CENTERED = 0` and the reference month | `summary()` |
| **Predictor coefficients** | Direction and magnitude of effects such as Year and Month | `summary()` |
| **Standard errors** | Uncertainty around each coefficient estimate | `summary()` |
| **Test statistics** | Effect size relative to its uncertainty, usually a t value | `summary()` |
| **p-values** | Evidence that a coefficient differs from zero | `summary()` |
| **Random-effect variance** | Variation among Sites, Site-Years and residual survey-level variation | `summary()` |
| **Confidence intervals** | Plausible range for the true coefficient value | `confint()` |
| **Annual percentage change** | Back-transformed Year effect on the `Abundance + 1` scale | calculated from the Year coefficient |

# Estimated marginal means (EMMs)

Estimated marginal means are **model-adjusted expected values**. They are useful when a fitted model contains other predictors that also influence the response.

For example, if abundance or richness varies among sampling months, the raw annual mean may partly reflect which months happened to be sampled in that year.

An EMM asks:

> What does the fitted model estimate for a particular year after accounting for the other terms in the model?

This is different from a raw arithmetic mean.

## Raw mean versus EMM

| Quantity | Question |
|---|---|
| **Raw mean** | What was the arithmetic mean of the surveys actually conducted that year? |
| **EMM** | What is the model-adjusted expected value for that year after accounting for the other model terms? |

For example, if one year was sampled mostly in months with naturally high fish abundance, its raw annual mean may be relatively high. The EMM adjusts for this imbalance using the fitted model.


## Why use Year as a factor?

The continuous-year model: Response ~ YEAR_CENTERED + ... answers:

> What is the overall long-term rate of change?

The factor-year model: Response ~ YEAR_FACTOR + ... answers:

> What is the adjusted expected richness in each sampled year?


```{r}
m_abundance_year <- lmer(
  Log_Abundance ~ YEAR_FACTOR + MONTH_FACTOR +
    (1 | SITE) +
    (1 | SITE_YEAR),
  data = survey_abundance,
  REML = TRUE)
```


## EMMs values

```{r}
abundance_emm <- emmeans(
```
